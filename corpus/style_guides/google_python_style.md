# Google Python Style Guide

The Google Python Style Guide provides conventions for writing readable and
maintainable Python software.

## Functions

Functions should have a clear purpose and should remain reasonably small and
easy to understand.

Complex logic should be divided into smaller reusable functions.

## Naming

Function and variable names should be descriptive and follow consistent naming
conventions.

## Imports

Imports should be explicit and organized clearly.

Wildcard imports should generally be avoided.

## Documentation

Public functions, classes, and modules should include useful documentation when
their purpose is not immediately obvious.

Readable code, clear naming, and maintainable structure are preferred over
unnecessarily clever implementations.
