# PEP 8 - Python Style Guide

PEP 8 defines conventions intended to improve the readability and consistency
of Python code.

## Naming

Functions and variables should generally use lowercase names with words
separated by underscores.

Classes should normally use the CapWords naming convention.

## Indentation

Python code should use four spaces per indentation level.

## Imports

Imports should normally appear at the top of a file.

Imports should be grouped into standard library imports, third-party imports,
and local application imports.

## Code readability

Code should be structured so that it remains easy to understand and maintain.
Very complex expressions and excessively long functions reduce readability and
should be refactored when appropriate.
